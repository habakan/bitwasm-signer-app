# Samples

`seedqr-test-only.png` encodes the public BIP39 test mnemonic (`abandon` eleven times, then `about`) as a 12 word Compact SeedQR.

`psbt-ur-test-only.png` is a test transaction as a single-part UR `crypto-psbt` QR, the same one the browser demo uses.

These are public values. Never use them to hold funds or for real transactions; they are only for checking the app's QR scanning.
