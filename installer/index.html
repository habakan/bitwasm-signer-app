Install Signer Lockdown over USB

The phone never joins a network. This page talks to it over WebUSB, installs Lockdown and makes it the device owner. It works in Chrome or Edge.

Step 1

Prepare the phone

  • Factory reset it. Do not add a Google account, and set a screen lock
  • Tap Build number seven times in About phone, then turn on USB debugging in Developer options
  • If adb runs on this PC, stop it (adb kill-server) so the browser can claim the phone
Step 2

Choose the APK

Download signer-lockdown-<version>.apk from the releases and choose it here.
