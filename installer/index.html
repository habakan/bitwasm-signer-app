Install Signer Lockdown over USB

The phone never joins a network. This page talks to it over WebUSB, installs Lockdown and makes it the device owner. It works in Chrome or Edge.

Install an APK over USB

This installs the chosen APK over WebUSB and nothing else; it does not set a device owner. Use it for the signer without Lockdown, or on a phone that Lockdown has not locked. It works in Chrome or Edge.

Step 1

Prepare the phone

  • Factory reset it. Do not add a Google account, and set a screen lock
  • Tap Build number seven times in About phone, then turn on USB debugging in Developer options
  • If adb runs on this PC, stop it (adb kill-server) so the browser can claim the phone
Step 2

Choose the APK

Download signer-lockdown-<version>.apk from the releases and choose it here.

Choose the APK to install. For the signer, that is bithanko-<version>.apk from the releases.

SHA-256 -
SHA256SUMS

Choose SHA256SUMS from the same release to check it automatically. Without it, compare the value above with the release page and tick the box yourself.

Step 3

Install

    Something else on this PC is using the phone. Stop it and this page connects on its own.

    • adb: run adb kill-server in a terminal. Android Studio and the emulator start adb again while they are open, so close them first
    • Another tab of this page, or its installed app window: close it
