# 署名アプリを試す

<sup>[English](../guide.md)</sup>

<Demo />

このページのスマホでは、署名アプリのブラウザ版デモが動いています。アプリと同じRustの署名エンジンをWebAssemblyにしたもので、テストネットで動きます。下の手順をこの中で試してください。デモは公開されたBIP39のテスト用の単語だけを使います。そのアドレスに本物のビットコインを送らないでください。

## 1. テスト用の鍵を読み込む

**テスト用の鍵を使う** を押します。BIP39のテスト用の単語(`abandon` を11回と `about`)を読み込みます。

ウォレットの画面に、フィンガープリント `73c5 da0a` が出ます。ウォレットアプリに出るフィンガープリントと比べると、両方が同じ鍵を使っているか確かめられます。

## 2. ウォレットアプリと接続する

**ウォレットアプリと接続する** を押します。SparrowやNunchukなどの見るだけのウォレットに渡す公開鍵を、QRコードで表示します。秘密鍵は含まれていません。

## 3. 取引に署名する

1. **取引に署名する** を押します。アプリでは、ここでカメラが開き、ウォレットアプリのアニメーションQRを読み取ります。
2. **テスト用の取引を使う** を押して、テストネットの取引の例を読み込みます。
3. 確認画面に、送る金額、ネットワーク手数料、すべての送り先が出ます。ウォレットアプリのアドレスと見比べてから1件ずつチェックを入れ、最後までスクロールします。
4. **署名する** を押し、もう一度 **署名する** を押します。
5. 署名した取引がQRコードで出ます。アプリでは、これをウォレットアプリで読み取り、ウォレットアプリから送金します。

## 4. 新しいウォレットを作る

ウォレットをロックしてから、**新しいウォレットを作る(デモ)** を押します。安全な乱数かサイコロで単語を作り、紙に書き写し、短いクイズで確かめる流れを試せます。**この単語のでき方を見る** では、乱数から単語ができる計算を順に見られます。

ブラウザで作った単語は、手順を試すためだけのものです。本物の資金に使う単語は、ネットにつながないスマホのアプリで作ってください。
