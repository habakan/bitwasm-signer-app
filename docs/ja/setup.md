# セットアップ方法

<sup>[English](../setup.md)</sup>

セットアップは「どうアプリを入れるか」と「どうアプリを使うか」の2つの選択です。この署名アプリでは、どちらもリスクと手間のトレードオフに合わせて選べます。

1. [どうアプリを入れるか](install.md): 誰が配ったものを信頼するか。このサイト、自分のGitHub Pages、作者のリリース、自分のビルドから選びます。
2. [どうアプリを使うか](use.md): 鍵を端末に残すか、端末をどこまで制限するか。減らせるリスクと失う利便性を比べて選びます。
3. [クイックスタート](quickstart/index.md): 1と2を組み合わせた、代表的な5つのパターンの手順です。画面を見ながら進められます。

どこで何を守っているかは、[セキュリティ仕様](security.md)にまとめています。

## 対応しているプラットフォーム {#platforms}

iPhone(iOS)とAndroidに対応しています。どちらもネイティブアプリとしてビルドできますが、Webアプリ(PWA)ならすぐに使い始められます。Webアプリは一度オンラインで開いて取り込めば、そのあとはオフラインで動きます。どの形でも、同じ署名エンジン(WASM)を動かします。

| | ネイティブアプリ | Webアプリ(PWA) |
| --- | --- | --- |
| iPhone | 自分でビルド(Xcode)。リリースは今後の予定 | Safariでホーム画面に追加。鍵の保存はiOS 18以降 |
| Android | リリースのAPK、または自分でビルド。[Signer Lockdown](lockdown.md)を使える | Chromeでホーム画面に追加。鍵の保存にはGoogleアカウントが要る |
